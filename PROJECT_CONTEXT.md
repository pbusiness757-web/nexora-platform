# PROJECT CONTEXT

## PROJECT

Nexora

## PROJECT TYPE

Crypto-to-Bank Payout Infrastructure Platform

## POSITIONING

Nexora is not a crypto exchange.

Nexora is a financial infrastructure platform that allows businesses and individuals to send cryptocurrency and receive local currency payouts.

## MAIN ADVANTAGE

Corporate bank account payouts.

Supplier payments.

Contractor payments.

Business settlements.
