# CRYPTOPAYOUT

## PROJECT OVERVIEW

CryptoPayout — международная платформа криптовалютных выплат.

Основная задача сервиса:

Получать криптовалюту от клиента и осуществлять выплаты в национальных валютах на:

- банковские карты
- банковские счета физических лиц
- расчетные счета организаций
- электронные кошельки
- наличные через партнеров
