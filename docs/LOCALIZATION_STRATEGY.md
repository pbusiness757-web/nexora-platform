# LOCALIZATION STRATEGY

## PURPOSE

PayBridge must support multiple countries, currencies and languages from the beginning.

Localization is required for:

* Website pages
* Calculator
* Telegram Bot
* Admin Panel
* SEO pages
* Notifications
* FAQ
* Legal pages

---

# DEFAULT LANGUAGE

Russian is the default language for Phase 1.

# SEO LOCALIZATION

Each country should have its own SEO pages.

Examples:

## Kazakhstan

/ru/usdt-to-kzt

/kz/usdt-to-kzt

## Uzbekistan

/ru/usdt-to-uzs

/uz/usdt-to-uzs

## Azerbaijan

/ru/usdt-to-azn

/az/usdt-to-azn

## Kyrgyzstan

/ru/usdt-to-kgs

/ky/usdt-to-kgs

---

# CONTENT RULE

Do not use automatic machine translation directly on production pages.

All key pages must be reviewed manually before publication.

---

# MVP DECISION

For MVP:

Build technical localization support immediately.

Publish Russian version first.

Add local languages after first version is stable.
