# ROADMAP

## PURPOSE

This roadmap defines the step-by-step execution plan for PayBridge.

Goal:

Launch fast, validate demand, process first real transactions, then scale.

---

# PHASE 0 — FOUNDATION

## Goal

Prepare full project documentation and strategic architecture.

## Tasks

* Project Master Plan
* Site Architecture
* Brand Book
* Design System
* Hero Section
* Home Page Structure
* Admin Panel Architecture
* API Architecture
* Telegram Bot Architecture
* SEO Strategy
* Database Architecture
* Tech Stack
* Roadmap

## Result

Clear product blueprint before coding.

---

# PHASE 1 — WEBSITE MVP

## Goal

Launch trusted public website with live rates and request creation.

## Website Features

* Homepage
* Hero Section
* Live calculator
* Live crypto rates
* Live fiat rates
* Request creation form
* Request status page
* Business payments section
* Corporate account payout emphasis
* FAQ
* Contact page
* AML policy
* Basic SEO pages

## Result

Users can understand the service, calculate payout and create requests.

---

# PHASE 2 — BACKEND MVP

## Goal

Create backend API and database foundation.

## Backend Features

* PostgreSQL database
* Prisma schema
* Requests API
* Rates API
* Clients API
* Payouts API
* Admin authentication
* Basic reports
* Audit logs

## Result

Website and admin panel can work with real data.

---

# PHASE 3 — ADMIN PANEL MVP

## Goal

Create operational dashboard for processing requests.

## Admin Features

* Login
* Dashboard
* Requests list
* Request details
* Status management
* Payout management
* Rates management
* Clients
* Reports
* Settings

## Result

Operators can manage all requests and payouts manually/semi-automatically.

---

# PHASE 4 — TELEGRAM BOT MVP

## Goal

Create Telegram channel for requests, support and status updates.

## Bot Features

* Calculate rate
* Create request
* Show payment details
* Track request status
* Contact support
* Operator notifications

## Result

Clients can use PayBridge directly from Telegram.

---

# PHASE 5 — SEMI-AUTOMATION

## Goal

Automate key parts without losing control.

## Features

* Crypto transaction monitoring
* Automatic request status updates
* Rate auto-updates
* Operator alerts
* Basic AML flags
* Request expiration timer

## Result

Faster operations with human control.

# CORE RULE

Do not build advanced features before first real transactions.

First:

Launch.

Validate.

Process.

Improve.

Scale.
